# Banking Core Java

A Java 21 learning project focused on core backend and object-oriented programming concepts through a simple banking domain.

## Tech Stack

- Java 21
- Maven
- JUnit 5

## Concepts Covered

- Object-Oriented Programming
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Interfaces
- Abstract Classes
- Exception Handling
- Custom Exceptions
- Collections
- Generics
- Lambdas
- Stream API
- Immutability
- equals() and hashCode()
- Unit Testing

## Domain Model

- Customer
- BankAccount
- Account
- SavingsAccount
- CurrentAccount
- Transaction
- TransactionType

## Features

- Create customers
- Create savings and current accounts
- Deposit money
- Withdraw money
- Apply overdraft rules
- Maintain transaction history
- Filter and aggregate transactions using Stream API
- Validate business rules using custom exceptions
- Verify behavior with JUnit tests
